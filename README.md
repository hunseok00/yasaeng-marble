# 🐎 야생마블 (Yasaeng Marble)

**야생마 동아리** 전용 주루마블 — 브라우저 하나로 즐기는 술게임 웹 서비스.
서버·DB·설치·회원가입 전부 없음 — 진행자 노트북 + 빔프로젝터만 있으면 끝.

## 플레이 방법

1. 참가자 이름 등록 (2~8명, 색상 자동 배정)
2. 미션팩 · 강도(순한맛/보통/매운맛) · 종료 조건(바퀴/시간) 선택
3. 순서대로 주사위를 굴리고, 도착한 칸의 미션/벌칙을 수행!

### 강도의 의미

강도는 미션 수위가 아니라 **벌주의 양**을 결정합니다.
**미션을 성공하면 강도와 무관하게 술을 마시지 않습니다** — 벌주는 미션 실패, 벌칙 칸, 룰렛 당첨 등에서만.

| 강도 | 벌주 양 |
|---|---|
| 😇 순한맛 | 한 모금 (무알콜 OK) |
| 😀 보통 | 반 잔 |
| 🌶️ 매운맛 | 원샷 |

### 칸 종류 (40칸 보드)

| 칸 | 설명 |
|---|---|
| 🎤 미션 | 선택한 미션팩에서 랜덤 미션 — 성공하면 통과, 실패하면 벌주 |
| 🍺 벌칙 | 강도 설정에 맞는 벌주 (콤보 시 양 자동 UP 🔥) |
| 🍶 벌주 채우기 | 공용 벌주잔에 술을 붓는다 — 누군가 터질 때까지 쌓인다 |
| 💣 벌주 원샷 | 모서리 칸! 지금까지 채워진 벌주잔을 통째로 원샷 |
| 🎯 지목 룰렛 | 참가자 전원 + **낮은 확률로 🎙 진행자**까지 걸리는 랜덤 룰렛 |
| 🌶️ 강도 룰렛 | 마실 양(한 모금/반 잔/원샷)을 룰렛으로 즉석 결정 |
| 🃏 찬스 | 전진/후퇴/면제권/한 번 더 등 랜덤 카드 |
| 🍻 전체 이벤트 | 테이블 전체 원샷, 건배 릴레이 등 집단 미션 |
| 😴 쉬어가기 | 무사통과 |
| 🏁 START | 한 바퀴 완주 시 벌칙 면제권 🎫 보너스 |

낮은 확률로 **⚡ 서프라이즈 히든 이벤트**(떼벌칙 등)가 발동됩니다.
보드 중앙에는 동아리의 상징, 야생마 🐎 들이 뛰어다닙니다.

## 로컬 실행

ES 모듈을 사용하므로 정적 서버로 실행:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 배포 (GitHub Pages)

빌드 과정이 없는 순수 정적 사이트입니다. 이 폴더를 저장소 루트로 올리면
`.github/workflows/deploy.yml`이 push마다 자동으로 GitHub Pages에 배포합니다.
(저장소 Settings → Pages → Source를 **GitHub Actions**로 설정)

## 미션팩 추가하기 (기여 가이드)

[js/data.js](js/data.js)의 `PACKS`에 항목을 추가하면 시작 화면에 자동으로 나타납니다:

```js
myPack: {
  name: '나만의 팩',
  emoji: '✨',
  desc: '팩 설명',
  missions: [
    '미션 문구 1',
    '미션 문구 2',
  ],
},
```

PR로 새 미션팩 기여를 환영합니다! 🎉

## 구조

```
juru-marble/
├── index.html        # 시작 설정 / 메인 보드 / 결과 3개 화면
├── style.css         # 빔프로젝터 기준 고대비·큰 폰트 다크 네온 테마
└── js/
    ├── game.js       # 상태 관리 + 턴 진행 루프 + 벌주잔/콤보 규칙
    ├── data.js       # 미션팩/벌주/찬스카드/40칸 보드 정의 (컨텐츠 확장 지점)
    ├── roulette.js   # 범용 가중치 룰렛 스피너 (지목/강도 재사용)
    └── audio.js      # Web Audio 합성 효과음 (에셋 파일 불필요)
```

> ⚠️ 즐거운 음주는 적당히! 순한맛 모드에는 무알콜 대체 미션이 포함되어 있습니다.
